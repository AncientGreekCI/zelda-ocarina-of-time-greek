# Glossary for The Legend of Zelda: Ocarina of Time (Ancient Greek)

Master renderings are polytonic Ancient Greek.
Terminology is strictly harmonized with previous Zelda translations (*A Link to the Past*, *Oracle of Ages*).

**Tags:**
- **V** = Verified / taken directly from ALttP & Oracle of Ages translations.
- **P** = Proposal tailored for Ocarina of Time (NT / LXX Greek style).
- **C** = Candidate / pending confirmation.

---

## Translation Rules

1. **Foreign & Proper Names:** Transliterated in New Testament / Septuagint style. Indeclinable unless an explicit declension pattern is specified in the notes.
2. **Capitalization:** Named proper locations, titles, artifacts, and institutions capitalize each significant word (e.g., *τὸ Κύριον Ξίφος*, *ὁ Ναὸς τοῦ Χρόνου*, *ὁ Δρυμὸς τῆς Πλάνης*).
3. **Engine Tokens:** Engine codes like `[NAME]`, `\x08`, `\x05\x41`, `BOX_BREAK`, etc. must remain untouched and never inflected. Sentences are structured so that `[NAME]` fits naturally in apposition or vocative/nominative slots without grammatical awkwardness.
4. **Lexical Consistency ("One English word, one Greek word"):**
   - **sword** $\to$ *τὸ ξίφος* (never μάχαιρα)
   - **shield** $\to$ *ὁ θυρεός* (never ἀσπίς)
   - **princess** $\to$ *ἡ βασιλίς* (Zelda, Ruto)
   - **queen** $\to$ *ἡ βασίλισσα* (Gohma, fairy queens)
   - **fairy** $\to$ *ἡ νύμφη* (Navi, Great Fairies)
   - **temple** $\to$ *ὁ ναός*
   - **dungeon / prison** $\to$ *τὸ δεσμωτήριον*
   - **chest** $\to$ *ἡ κιβωτός*
   - **map** $\to$ *ὁ χάρτης*
   - **compass** $\to$ *ἡ πυξίς*
   - **button** $\to$ *τὸ πλῆκτρον* (e.g. *Πίεσον τὸ πλῆκτρον [A]*)
   - **save / continue / quit** $\to$ *Σῶσαι / Μένειν / Ἐξελθεῖν*
5. **Register:** Prefer New Testament and Septuagint (LXX) Hellenistic Greek vocabulary, maintaining classical elegance.
