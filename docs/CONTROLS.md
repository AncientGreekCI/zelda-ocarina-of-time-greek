# Ocarina of Time — Laptop Keyboard Controls

This control layout is configured automatically in RetroArch via configuration overrides for **Mupen64Plus-Next**.

---

## 🎮 Controller Layout

| N64 Function | Keyboard Key | In-Game Action / Ergonomics |
| :--- | :--- | :--- |
| **Analog Stick** | `W`, `A`, `S`, `D` | Link's full 360° analog movement (Up, Left, Down, Right) |
| **Z-Trigger** | `Spacebar` | **Z-Targeting / Lock-on** (Left thumb — full movement while locking) |
| **R Button** | `Left Shift` | **Shield / Guard** (Left pinky — block while moving and targeting) |
| **B Button** | `J` | **Sword Attack** (Right index finger) |
| **A Button** | `K` | **Action / Roll / Jump Attack** (Right middle finger next to sword) |
| **C-Up** | `↑ Up Arrow` | **Navi / First-Person Camera** |
| **C-Down** | `↓ Down Arrow` | **Equipped Item / Ocarina Note** |
| **C-Left** | `← Left Arrow` | **Equipped Item / Ocarina Note** |
| **C-Right** | `→ Right Arrow` | **Equipped Item / Ocarina Note** |
| **Start** | `Enter` | **Pause / Inventory / Equipment Subscreens** |
| **L Button** | `Q` | **Toggle Minimap** |

### Conflicting Hotkeys Disabled in Override:
- `Spacebar` previously toggled **Fast Forward** in RetroArch; it has been unbound so it functions strictly as **Z-Targeting**.
- `K` previously triggered **Frame Advance**; it has been unbound so it functions strictly as **Action / Roll**.
